ダビマス配合研究所 v2.8｜実測因子・最終血統の動的再構築
作成・確認日：2026年11月6日
ベース：v2.7（GitHub kuronekoTakeko/dabimas-lab と主要3ファイルのGit blob SHA一致を確認）

【目的】
生産フローに沿って実際に作った自家製種牡馬の「本人因子」を登録した際、
過去の仮血統を無断で更新せず、現在の親子記録から最終産駒の5代血統を再構築し、
独立クロス候補・判明因子を参考再集計して確認できるようにする。

【今回の改善】
1. 保存プランの編集画面に「v2.8｜自家製種牡馬の実測因子を反映した最終血統」を追加。
2. 9工程で連結済みの最終産駒から親子参照を逆にたどり、補助X・本気型仕込み枝も含めて再構築。
   親子関係を変えるのではなく、表示用の新しい血統を組み立てる。
3. 「自家製馬」タブで「実際に生産」と記録し、本人因子を入力済みの牡馬だけ、
   その本人が最終5代の祖先位置に存在するときに反映する。
   目標因子・仮馬の未実測因子を実測値として加算しない。
4. 最終5代のどの祖先位置（例：S／SS／DDS）に登録実測因子が反映されたか明示。
5. 最終産駒・最終種牡馬・最終肌馬の5代血統と独立クロス候補、判明因子の研究用参考再計算。
   因名が未確認なら未確認として扱う。同じ自家製個体を複数位置で数える場合も二重加算しない。
6. ゲーム内で「本人因子が0個」と確認した記録は、空欄（未確認）と区別する。
7. v2.4本気型の内部仮名（「通常工程1の仮馬」等）が保存時に変わる問題に対応。
   既存プラン内の正式な連結IDから対応が立証できる仮名のみを受け入れる。
8. 親が見つからない、参照が循環、登録祖先の実名が矛盾する場合は警告を表示。
   不明な祖先名を推測して置き換えない。
9. データ管理・保存キーを変更しない。新しいプラン比較ボタンも追加しない。
10. ヘッダ、タイトル、JavaScriptバージョン、Service Workerキャッシュをv2.8へ。

【利用方法】
1. 既存PWAの「データ管理」で最新版JSONのフルバックアップを取得。
2. 通常どおり、配合理論→中心種牡馬→目標レース→能力方針→マイルド／本気型で作成。
3. 生産フローで、目標の本人因子と必要な牡牝を確認。
4. ゲーム内で自家製牡馬を生産・種牡馬化し、因子が確認できたら「自家製馬」を開く。
5. 該当仮馬の「記録を編集」で「実際に生産」を選択し、「速・長」などを登録。
   因子が0個と確定したときだけ「なし」。未確認のままなら空欄にする。
6. 「保存プラン」の該当プランを開くと、v2.8の実測反映プレビューが現在の記録から自動作成される。
   再計算はブラウザ内の表示専用。保存済みの仮馬祖先・親子参照・既存プランを上書きしない。
