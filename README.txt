ダビマス配合研究所 v4.6｜中心種牡馬の「馬名を選ぶだけ」内部異因名比較
更新日：2026-11-09

【v4.6の追加実装】
1. 自動設計の中心種牡馬メニューに、取得済み種牡馬から至高一次候補が作れる馬名ごとの選択肢を追加。
   例：ディープインパクトを選ぶと、その馬名の所持済み異因名3頭セットを最大24組比較。
2. 個別の異因名セット直接指定と「馬名も自動選択」を引き続き利用可能。
3. 馬名単位で、各セットに名牝6頭・補助種牡馬Xの既存探索を行い、血統品質・判明根拠・研究指数を比較。
4. 候補比較件数、選択モード、実際に採用した異因名セットID、候補別の簡易監査を新規プランの autoDesign21.autoAnchor45 内に記録。
5. 候補抽出枠を全体最大240組、同名最大40組に広げ、馬名選択時の探索を最大24組に制限（従来は同名最大4組・全体120組、中心馬自動選択上位6組）。
6. JSモジュール research-family-search.js を新設。SWキャッシュを v46 に更新。

【使い方】
「自動設計」→「② 至高の中心種牡馬」でディープインパクトまたはキングカメハメハなどの馬名を選ぶ。異因名の組合せはシステムが比較する。
レース・能力方針・配合規模を選び「この条件で配合プランを自動作成・保存」。詳細指定はメニュー後半に残っている。

【重要な制限】
・この版で完成したのは馬名単位での候補組合せ比較の実装。配合全探索、実際の生産工程削減、至高の実機成立判定は未完成。
・現行の9工程マイルド／9〜20工程本気型の既存生産フローは変更していない。
・血統の完全な公開マスターCSVと名牝ランクがない場合、実際の配合プランを生成できない。
・全組合せを網羅する最適解は保証しない。馬名24組・全体240組上限を設け、各組の繁殖牝馬とXの探索も候補数制限あり。
・ダビマス全書と公開外部ツールとの全件血統照合、実際のゲーム内生産、実データを使った大量探索は未実施。
・研究評価は能力値を予測するものではなく、ゲーム内至高成立確認でもない。
