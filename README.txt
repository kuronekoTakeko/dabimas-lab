ダビマス配合研究所 v0.8（自家製馬・世代継承）

● 新機能
- 「自家製馬」タブ：種牡馬・繁殖牝馬（公開データ）または自家製馬同士を親として選択
- 産駒の5代種牡馬血統31枠を照合し、判明分を祖先15枠の自家製馬として登録
- 仮想生産案と実際に生まれた馬を区別。性別、ゲーム内の実測SP/ST、メモを記録
- 登録した自家製牡馬・牝馬を次の交配の父・母に選択可能。世代を重ねた祖先の位置を再計算
- 保存プランと任意の工程に自家製馬を紐づけて、プラン編集画面にも一覧を表示
- 血統付き自家製馬はJSONバックアップに含まれる。v0.7のJSONの読込にも対応
- 既存の種牡馬所持・繁殖牝馬・至高候補・配合9工程・X枠検索を維持

● 制限・注意
- 作成した血統は種牡馬の祖先配置を機械的に引き継いだものです。ゲーム内の配合理論成立保証ではありません。
- 自家製馬本人の因子は自動予測しません（空欄）。子系統は父の子系統を暫定的に引き継ぎます。
- 自家製馬を親にするには実際にゲーム側で繁殖利用可能か確認してください。
- SP/ST予想、子系統ボーナスの正確な能力加算、途中産駒の最低能力基準の自動計算は未実装です。
- 自家製馬の馬名は同じアプリ内で重複できません。既存登録の子孫の親になっている馬は削除できません。
- 公開CSVは利用者の端末に個別に取込。配布物にCSV本体は同梱していません。

● 更新方法
1. 現在のアプリの「データ管理」からJSON書き出し。
2. この6ファイルをGitHub dabimas-lab のルートに上書きアップロード。
3. GitHub Pagesでv0.8と確認、種牡馬52頭と保存プランが残っていることを確認。
4. 自家製馬タブで直接配合を試し、仮馬を登録。次の親に使って血統が継承されるか確認。
