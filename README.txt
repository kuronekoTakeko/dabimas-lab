ダビマス配合研究所 v1.4｜至高専用・公式BC向け研究版

今回の目的：至高の配合に開発範囲を絞り、候補の抽出から9工程の生産プランへの導線を一本化しました。奇跡は将来実装の候補として残します（現時点では未実装）。

追加機能：
・「至高探索」タブ。所持種牡馬の同名・因名違い3頭で因子6種類以上を抽出。権利数0も所持扱い。
・検出した3頭から「9工程の新プラン」を作成。正式成立は未確定として保存。
・保存済み9工程の仮連結後、指定祖先・因子、研究対象SP/ST子系統を比較して表示。
・v1.3の「名牝限定探索」「一括連結」「最短生産ナビ」「ゲノム解析」「データ管理」を維持。

確認すべきこと：
・因子6種類と3×4×5の位置だけでは「至高成立」を自動で保証できません。ゲーム内配合補助で確認してください。
・比較用指数は能力値、産駒SP/ST、実際のニトロボーナス値、公式BCの成績予測ではありません。
・未生産の仮馬での9工程はゲーム内で完成できたと証明するものではありません。

GitHub Pagesへの更新：
1. 先にデータ管理→JSON書き出しでバックアップを保存。
2. ZIP解凍後の6ファイルをリポジトリ直下へ同名上書きし、Commit changes。
3. 更新されたアプリの「至高探索」タブを確認。
4. 既存プランは上書きせず、検証用に新しいプランを作成できます。
