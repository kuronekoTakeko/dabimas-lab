【v4.1 変更】
・research-flow-guard.js を新設。自動生成したマイルド型9工程の父母依存、産駒性別、計画ID、血統31枠を一括検証。
・9工程をメモリ内で仮連結し、すべて成功してから永続化。途中で欠損・矛盾が見つかると、新しく生成した計画・仮馬を取り消す。
・research-flow-guard.js が読み込まれない場合も成功とみなさず、新規自動設計の部分保存を避ける。
・旧プランの編集、所持馬・権利数0、ゲノム・自家製馬記録の既存形式は変更しない。localStorageキーは dabimas_lab_v01 のまま。
・サービスワーカーキャッシュを dbms-v41-1 に変更。
・ユーザー操作による手動の仮連結には従来どおり工程ごとの保存を適用。自動設計の新規作成にだけ一括判定を適用。
