ダビマス配合研究所 v3.0｜マイルド型・生産前の自動点検
確認日：2026-11-06
改修ベース：v2.9 GitHub更新用ZIP（GitHub上のv2.9を主要ファイルで照合）

【目的】
早く実際に生産できる状態を目指しつつ、未確認の至高成立条件を「OK」と誤判定しない。
通常ユーザー画面に検証用の余計なタブや比較ボタンを増やさない。
マイルド型9工程の自動生成結果と保存プラン内に「生産前の自動点検」を表示する。

【変更点】
1. マイルド型9工程の保存プランに対し、読み取り専用で以下を判定：
   - 完成産駒の種牡馬祖先31枠が連結できるか
   - 至高用SSS/DSSS/DDDSSの3位置と因子が指定3頭に一致するか
   - 同名の異なる登録種牡馬3頭で、因子6種類を確認できるか
   - 9工程の各親馬・性別・産駒が保存プランの親子関係と一致するか
   - 所持扱いの種牡馬が途中で非所持に変更されていないか
2. 機械的な一次条件が揃っていても「ゲーム内の至高成立は未確認」と明示。
3. 「全兄弟姉妹による阻害／5代血統表に現れない牝馬の血縁」と「年号付き種牡馬の扱い」は未判定として残す。
4. SP/ST、ニトロ、産駒本人因子、実際のクロス効果の架空数値は表示しない。
5. 点検は既存プラン・所持登録・仮馬を編集せず表示のみ。比較用タブは追加しない。
6. バージョン表記をv3.0に更新し、Service Workerのキャッシュをdbms-v30-1へ更新。
