ダビマス配合研究所 v3.5｜血統品質を優先する候補選択
作成：2026-11-06　基盤：ユーザー提供 v34 ZIP

改修内容
・新設 research-quality.js：v34血統監査結果から構造的な欠損・衝突を抽出し、候補を比較。
・マイルド型：至高中心候補が一致する探索結果の中から、祖先の構造不備が少ないものを優先。同等なら既存探索順位を維持。
・本気型：品質順に選んだ最大3基礎候補を探索し、構造品質が同等の候補間で従来の研究用スコア・工程数を比較。
・因子が未収録なだけでは不成立としない。成立確定・能力数値・ニトロ効果等も断定しない。
・採用プランの autoDesign21.dataQuality35 に、構造の問題数・欠損枠・血統充足率など監査サマリーを格納。
・v34血統監査の結果表示を維持。結果画面へ選択基準の説明を追加。
・公開マスターCSVや第三者のコード・データを同梱していない。研究アルゴリズムは独自実装。

注意・制約
・探索上限は依然あり、315頭と全名牝の全組合せの最適保証はありません。
・現在の候補品質比較は欠損・衝突の一次チェックであり、ゲーム内の至高成立を保証しません。
・本気型の内部ビーム探索スコアはまだv34の研究用仮説を利用します。
・「因子6種類未達」が監査上要修正でも因子未収録の可能性を否定できないため、候補順位の構造欠陥扱いはしません。
・v34以前の既存プランを再評価して並べ替える変更はありません。

更新方法
1. 2台とも現在のPWAからJSONをバックアップ。端末間データ差に注意。
2. ZIPの8ファイルをGitHubリポジトリ直下に上書き・追加。
3. 新規ファイル research-quality.js の配置を忘れないこと。
4. GitHub Pages反映後にCtrl+Shift+R。ヘッダー v3.5 を確認。
5. 公開マスターCSVが必要な場合は各PCで既存の取り込み手順を使用。
