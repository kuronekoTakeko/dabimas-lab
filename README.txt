ダビマス配合研究所 v1.6｜同因名・異因名の有効クロス因子を分類

【追加・修正】
- v1.5 のクロス重複分類を同梱。v1.4から直接v1.6へ更新できます。
- 有効な独立クロス候補について、同名種牡馬の「同因名は1回」「異因名はそれぞれの因子を合算」する研究用集計を追加。
- 覇走〔速〕×覇走〔速〕→速1、覇走〔速〕×極走〔速・速〕→速3を自動テスト。
- 保存した9工程プランの完成血統レポートに「v1.6｜有効クロス因子（判明した因名のみ）」を追加。指定3頭の因名は保存プランから照合。
- 保存プランの横並び比較に、確認できたクロス因子〔短・速・走・長・中・底〕および因名未確認枠を追加。
- 31枠の因子の位置数と、有効クロス因子の数を分離表示。ニトロの正確な加点とは区別。
- これから生成する仮馬には、判明している本人因名の情報を次世代の血統情報へ継承。古い仮馬で不明な部分は推測しない。
- 既存所持チェック/保存プラン/名牝登録/仮馬/JSONバックアップ形式を維持。

【注意】
- これはゲーム内で点滅する因子や至高配合の成立を保証するものではありません。
- 元CSVに因名のない祖先馬は「因名未確認」とし、確定分には足しません。
- 同じ因名で矛盾する因子情報があれば、計算に入れずに警告を表示します。
- 正確なニトロ、子系統の確定加点、最終産駒の予想SP/STは未実装です。
- 研究案の旧暫定指数は血統31枠の位置数ベースであり、有効クロス因子ランキングではありません。
