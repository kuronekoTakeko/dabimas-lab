ダビマス配合研究所｜v4.9 開発版（GitHub Pages 上書き用ZIP）
=========================================================
作成日：2026-11-09
基盤：ユーザー提供のv4.8 ZIP。アプリの保存キー・旧JSON形式を変更していません。

【v4.9の変更】
1. 至高中心馬の異なる3登録IDを3/4/5代へ割り当てる全6通りを生成し、公開血統で既知の4代・5代の子系統や31枠などを参考評価。
2. 一次配合評価：選択候補セットが3組以下なら各6配置、4組以上なら各最大2配置を深堀り前に調査。元のv4.8配置は必ず候補に含める。これは処理量を絞った部分探索。
3. 本気型の可変仕込みを比較する枠を従来の上位3案から4案に拡大。異なる異因名セットを優先し、空き枠では異なる3/4/5配置を優先。
4. 位置・因名・因子・種・肌・最終産駒の31枠TXTを検査する独立ローカル監査（research-txt-review-v49.js / tools/audit-pedigree-txt-v49.js）。公開ページでは読み込まず、実運用でCSV/所持データを書き換えない。
5. v4.9の単体テスト10件追加（テスト名 tests/v49-txt-and-search.test.js）。旧v4.7統合テストは新しい選考関数も許容するよう更新。
6. サービスワーカーのキャッシュ名 dbms-v49-1、ページ表示をv4.9に更新。

・ディープインパクト本気型2400m・19工程：種31/31、肌31/31、最終31/31。親の祖先の30枠継承で不一致0。3x4x5の異なる3登録因名・6種類の因子を確認。
・キングカメハメハ本気型1600m・18工程：同上。ノウンファクトの3x3同名重複を検出。近い重複の影響はゲーム側要確認。
・いずれも外部ゲーム内至高成立は未確認。全兄弟姉妹の血統阻害は種牡馬祖先だけから判定不可。
・キンカメ2012を同名グループとして扱うのは研究上の扱い。ゲーム仕様での同名成立確認は未実施。
・外部の公開血統データとTXTの実馬名/因子の完全突合は未実施。内部矛盾ゼロと外部照合済みは異なる。
・2つの個別TXTと所有315頭JSONはGitHub用ZIPに同梱していません。

【導入手順】
1. 本番PWA「データ管理」から現行JSONのバックアップを保存（必須推奨）。
2. GitHub Pagesの公開ディレクトリへZIPのファイルを上書きしてコミット。
3. ブラウザを更新してv4.9表示を確認。既存の保存プラン・実馬・ゲノムは消去しない。
4. 自動設計には公開血統マスターCSVの取込みが必要。端末ごとの保存状態は自動同期されない。
