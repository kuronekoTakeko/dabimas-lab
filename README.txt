ダビマス配合研究所 v1.8｜所持優先・BC研究版

▼ 絞り込みルール変更
・種牡馬は【所持チェック】だけで候補対象にする。権利数が0でも除外しない。
・「残権利1以上に限定」チェックは削除。
・至高候補・13工程仕込みの候補に所持チェック済みの全該当馬を使用。
・過去の権利数はデータ互換性と参考記録のため保持するが、探索順位には使わない。
・未所持馬は引き続き仕込み用種牡馬候補に含めない。

▼ 実践ブログから取り入れたこと
・まず対象BCの距離・コースに応じてSP/STの目標を選ぶ。
・至高3×4×5を固定してから、空き4/5代目に子系統・走/中因子・別系統の追加クロスを置く。
・4代目の子系統を重視、5代目の効果・系統重複は不確実とする。
・短距離のSP特化と中長距離のST特化を別方針で評価。最終的に肌馬能力・ゲノム解析が重要。
・13工程試算画面に「公式BCの目標」セレクトを新設。選択に応じて候補の並び順を変え、4/5代目のSP/ST研究系統数と祖先因子位置数を表示。
・表示数はニトロ確定値、公式BC勝率、ゲームのSP/ST効果量ではない。
