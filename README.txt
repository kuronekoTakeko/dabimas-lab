ダビマス配合研究所 v1.9｜所持種牡馬から追加クロス4枠の自動配置

【v1.9の新機能】
・v1.8の13工程仕込みメニューに「取得済み種牡馬から配置を自動探索」ボタンを追加。
・所持チェック済み、同名で異因名の3因子ペアを対象に、追加クロスA（父系P2×母系Q1）と追加クロスB（父系P1×母系R2）を組み合わせ・左右の因名も自動で試算。
・至高のディープ3×4×5、元の名牝6頭、補助種牡馬Xは固定したまま候補を比較。種付け権利数0の馬も候補に含める。
・追加クロス成立の研究用確認、31/31の血統位置、指定3/3、既知の有効クロス因子と4/5代の研究対象系統に基づいてスピード／バランス／スタミナ別の参考順位を表示。
・上位5案を表示し「この配置を試算」で13工程の詳細を展開。別プランとして保存した場合のみ、仕込み牝馬4頭を新しい仮馬として保存。元のプランと所持情報は変更しない。
・条件を満たす所持ペアが少ない場合や完全血統がない場合は、成立を捏造せず理由を表示。
・対象組み合わせは最大1,800試算。上限に達した場合は部分探索と表示。

【制限】
・現在の自動化範囲は「追加2クロス、4つの準備牝馬の父親」に限ります。6頭の名牝や補助Xを同時に自動変更する機能、15工程以上の可変工程探索は未実装。
・研究用評価指数は実際のSP/STやニトロの計算式ではありません。至高成立の全兄弟姉妹条件もゲームで確認が必要です。
・最終繁殖牝馬の能力・因子・相性等の実測値は推定せず、計画上の仮馬であることを表示します。
・GitHub Pagesへの更新前に必ずデータ管理からJSONバックアップを保存してください。

【導入】
ZIPの6ファイルをGitHubリポジトリ直下に同名上書きします。v1.8から直接更新可能。
保存プラン→至高の9工程プランを開く→「v1.9｜追加2クロスの仕込み牝馬」→BC目標選択→「取得済み種牡馬から配置を自動探索」→好みの案で「この配置を試算」→必要な場合だけ別プランに保存。

【データ】
localStorage保存キー dabimas_lab_v02_state を維持。旧データの上書きなし。CSV（たかな牧場）は端末ごとに取り込みが必要。
