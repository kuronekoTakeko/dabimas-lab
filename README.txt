ダビマス配合研究所 v0.3

主な変更：保存プラン機能
1. 種牡馬図鑑で所持チェック。公開CSVはデータ管理から取り込み。
2. 至高候補で因子6種類の一次候補を検索し、「この候補を計画に保存」を押す。
3. 「保存プラン」から過去の計画を開いて、目標レース・各工程・最低許容SP/ST・実測結果・進捗を編集。入力は自動で端末に保存。
4. 新しく検索しても保存済みプランは消えない。手動で計画を作ることも可能。
5. データ管理のJSONバックアップは、所持チェック・能力記録・保存プランを含む。保存プランのみのJSONも書き出し可能。
6. v0.2と同じドメイン（オリジン）でv0.3に更新すれば、既存の所持チェック等を引き継げる。ローカルHTMLで開く場合はブラウザによって保存が不安定な場合がある。

注意：至高の因子候補は6種類因子だけによる暫定判定。実際の至高・奇跡成立検証、完成した代重ね工程の自動生成、SP/ST最小基準の自動計算、産駒予想値の自動計算は未実装。保存される工程は手動編集できるテンプレートです。
公開CSVの利用元：https://github.com/takana666/DBMSdata_search（CSVは同梱なし）
