1. 血統表は「最終産駒」「最終種牡馬」「最終肌馬」の3つの折り畳み表示。
   各表は5列×31祖先枠が1画面の横幅へ収まるコンパクト表示。
   旧仕様の「高さ792px／横幅780px以上」の内部スクロールをやめた。
   文字が小さい祖先枠はタップ・クリックして馬名／位置／本人因子／子系統を確認できる。
   画面幅320px、390px、PC幅1100pxのブラウザテストで横はみ出しなし。
   最終産駒の表のみ最初に開き、種牡馬・肌馬は閉じる。別々に開閉できる。
2. 自動生成結果・実測反映プレビューの不要な二重折り畳みを外し、各表を直接開けるよう変更。
3. 工程7（X×C2牝）で採用する補助Xについて、候補上位28頭だけの検索上限を改善。
   6牝馬の組合せ探索は候補数上限付きのまま、固定した各基礎牝馬構成については
   血統データが揃う取得済みX候補を全件走査。交互探索の後も再走査する。
4. 研究用X順位は、単純な同系統や祖先因子の位置数だけでなく、
   『独立クロス候補に入った因子（走・中・速・短・長など）』と
   『4～5代目のSP/ST研究対象子系統』を区別して評価。
   因子が本人に存在するだけで有効クロスに加点しない。派生祖先重複も独立クロスとみなさない。
   Xの選定結果・走査した候補数と追加独立クロス候補を、生産フローで短く表示。
   成立確定値・ニトロ・実際の産駒能力値を推定したわけではない。
5. 保存済み旧プランのXを勝手に差し替えない。従来の所持チェック・仮馬・ゲノム・
   プラン・保存形式・マスター保管キーには変更なし。
