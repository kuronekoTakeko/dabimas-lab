ダビマス配合研究所｜v3.1.1（5代血統表の見切れ修正）
更新日：2026-11-06

【対象】
v3.1 の GitHub Pages 公開PWA（kuronekoTakeko/dabimas-lab）

【不具合】
v3.1 では 5代血統表を固定高さに縮めたが、CSS Grid の暗黙的な自動行サイズが
16分割の祖先枠を実際の高さ以上に押し広げてしまい、下段が表外へはみ出した。
画面幅1539px／高さ850px の再現試験で、最大下側はみ出しが356.25px、
390px／844pxでは197.23pxだった。

【修正内容】
1. 5代血統表のグリッド行高を minmax(0,1fr) で固定し、列の min-height を 0 にする。
2. 16枠ある5代目は重複するパス表記を省略し、馬名・因子の表示領域を確保する。
3. 「祖先をタップ」からは馬名・因子・子系統・祖先位置を引き続き全文確認可能。
4. 最終産駒、最終種牡馬、最終肌馬の折りたたみ、クロス強調、至高指定位置は維持。
5. アプリ表示を v3.1.1、JSクエリを311、SWキャッシュを dbms-v311-1 に変更。

【自動検証】
Playwright Chromium で人工CSVマスター + 315所持・14プラン・116仮馬のバックアップを使用。
対象画面幅/高さ: 1539x850、1100x900、768x800、390x844、320x720。
各画面で最終産駒・種牡馬・肌馬の3表（合計15表）を測定。
・各表の祖先表示数31、5列表示：合格
・スクロール領域および祖先枠の横/縦はみ出し：いずれも0px
・タップした祖先情報の表示、3表の開閉：合格
・ディープ/キングカメハメハのマイルド型9工程を生成：合格
・所持登録315件、旧14プラン、旧116仮馬の内容を保持：合格
・未処理JavaScript例外：なし
・node --check app.js：合格（app.js自体はv3.1と同一）
注：使用した種牡馬・繁殖牝馬マスターはテスト用の人工データ。
　　公開CSVによる全315種牡馬×500繁殖牝馬の網羅的な探索テストは実施していない。
　　配合理論のゲーム内成立確認および実SP/ST評価も未実施。

【更新方法】
1. v3.1 の「データ管理」で必ずフルJSONバックアップを取得する。
2. ZIPに入った6ファイルをGitHubリポジトリ直下へ上書きする。
3. Pages反映後ブラウザで再読み込みし、先頭にv3.1.1と表示されることを確認。
4. 保存プランの最終産駒・種牡馬・肌馬の血統表を開く。
5. 見切れがなく、スクロール不要で31枠全体が見えることを確認する。

【保存データ保護】
保存スキーマは不変。app.js、manifest.webmanifest、icon.svgはv3.1から変更なし。
既存の所持・保存プラン・仮馬・ゲノムを削除/初期化しない。
個人バックアップおよびテストCSVはZIPには含めない。
Githubへの直接コミットは未実施。
