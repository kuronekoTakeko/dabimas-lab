ダビマス配合研究所 v1.1｜連結操作の改善版

v1.0からの変更点
- 手動連結時、「工程1→2→3→…」の次の未完了工程を見つけ、自動スクロールして案内します。
- 「次の未完了工程へ移動」ボタンを追加。任意の時点で続きを開けます。
- 「残りを1→9で一括仮連結」ボタンを追加。既に有効な仮馬は変更せず、未完了工程だけ順番に登録します。
- 必要な親馬が不足している、血統31枠が埋まらない、性別が不適切などのエラーがあればその工程で停止し、該当工程へスクロールします。
- 後から親馬を変更すると、影響のある後続工程の仮馬を無効扱いにし、再生成できます。古い仮馬の記録は自動削除しません。
- 保存プラン、所持チェック、公開CSV、自家製馬・JSONバックアップの形式はv1.0を維持します。

※この自動連結はゲーム内で種付けをする機能ではなく、アプリ内で未生産の「仮馬」を登録する機能です。
※至高・奇跡の配合成立、予想SP/ST、公式BCの強さを保証するものではありません。

GitHub更新
1. 公開中v1.0の「データ管理」からJSONを書き出してバックアップしてください。
2. ZIPを解凍し、index.html、app.js、sw.js、icon.svg、manifest.webmanifest、README.txtの6ファイルをリポジトリ直下に上書きアップロードしてください。
3. GitHub Pagesを再読み込み。v1.1と表示されることを確認してください。
4. 保存済みの9工程プランを開き、連結ボタンまたは一括連結ボタンを試してください。
