ダビマス配合研究所 v0.4

【更新内容】
・「血統分析」タブを追加。公開CSVの種牡馬・祖先15枠の因子と子系統を自動集計。
・保存プランで3代(SSS)・4代(DSSS)・5代(DDDSS)に各因名の馬を選び、父系・母系を組み合わせる9工程の仮ルートを生成。
・仮ルートは新しい計画として別に保存。元の計画や従来の工程・メモは保持。
・既存の v0.3 の所持チェック・保存プラン・能力記録は同じURLで更新すると引継ぎます。
・権利数0は引き続き所持として扱います。

【重要な限界】
・仮ルートは構造的に3×4×5の祖先位置を作る「骨組み」であり、実際のゲーム内の至高成立を保証しません。
・P1などの繁殖牝馬や種牡馬Xは未指定。5代血統全体とクロス・全兄弟姉妹、条件を完全には計算しません。
・「血統分析」は種牡馬の登録15祖先枠だけを数えます。最終産駒の完成血統のニトロ計算ではありません。
・子系統の効果量、産駒SP/ST、工程ごとの最低能力は不確定なため架空数値を表示しません。
・公開CSVは同梱しません。アプリ内の「データ管理」から公開元に直接アクセスします。作者の利用条件等を確認してください。
