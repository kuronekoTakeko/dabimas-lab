【v2.3の変更点】
・本気型のワンクリック生成を v2.2 固定13/15工程探索から、可変長の仕込み探索に変更。
・元の通常9工程を保存形式上の核として維持。P1・P2・Q1・Q2・R2の母方仕込みを、最終産駒の5代に残る範囲で追加。
・新たな仕込みは最大9工程（通常9＋仕込み9＝最大18工程）という構造上の範囲を使用。
・所持済み（権利数0を含む）の同名異因名ペアを全件調べ、重い血統試算は研究スコア順の上位24組までに制限。
・9工程の基礎名牝6頭／補助X候補は従来探索の上位2案を試す。各基礎案ごとに2500回を上限とした、幅3・最大4ラウンドのビーム探索。
・追加クロスは父母の独立クロス候補として検出されたものだけを評価。追加前より既知有効因子数と研究評価が改善する場合のみ採用。
・片側単独の仕込みも、研究上の4代目系統または判明クロス因子が改善する場合だけ追加。
・全候補で31枠を再計算し、指定 SSS / DSSS / DDDSS の馬名・因子が変わる設計は採用しない。
・新規プランには hard23.preparations、hard23.grafts と研究評価を保存。仕込み仮馬と通常9工程の仮馬を親子関係付きで新規記録。
・［保存プラン］編集画面に準備工程を表示。工程完了、最低SP/ST、ゲノム結果、メモを別々に編集・保存可能。
・保存一覧の工程数に仕込みを含める。マイルド型と旧13/15工程の既存データ・画面をそのまま維持。

【今回の探索の限界】
・完成版の完全な全血統最適化ではありません。9工程という基本骨格と取得済み種牡馬の組み合わせを維持します。
・最大18工程はこの骨格で5代以内の種牡馬枠に入る仕込みに関する上限です。20工程以上や6頭以外の全枝・自家製種牡馬の新規構成は次段階です。
・基礎牝馬とXの同時最適化は上位2基礎案の比較に限定されます。全500頭×全所持馬を網羅して最適解を保証する探索ではありません。
・取得済み種牡馬以外を仕込み種牡馬に選びません。名牝は公開データの古い名牝判定を含むため、ゲームで確認してください。
・保存した仮馬は、実際に生産済み・所持済みとみなしません。
・公式至高の成立阻害（全兄弟姉妹・体質・相性等）は判定できません。
・クロス独立性と因子名・同因名・派生祖先の分類は研究上の近似です。
・SP/ST実測予測、子系統の正確な補正、ニトロ段階、最低SP/ST合格基準は未実装。数字を捏造しません。
・ゲーム内の至高表示と育成結果の実測で、選定アルゴリズムを今後検証する必要があります。
