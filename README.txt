ダビマス配合研究所 v1.3｜最短生産ナビ・ゲーム内確認・ゲノム値記録

v1.2からの追加
- 保存済み9工程の上に「最短生産ナビ」を表示。9工程連結、指定3頭・因子6種類以上の血統配置の一次確認、ゲーム内至高表示の確認状況、工程別ゲノム記録を集約。
- ゲーム内の至高成立・不成立をユーザーが登録可能。アプリ側は至高成立を自動で確定しません（兄弟クロス等はゲーム内で確認）。
- 工程1〜9それぞれにゲーム内ゲノム解析のSP/ST最小・中央値・最大6項目を保存可能。全入力の妥当性チェックあり。
- 工程の最低許容SP/ST（数字／ランク）は従来のプラン工程と同期。数値条件がある場合はゲーム内ゲノム値の範囲と比較して参考情報を表示（SPとSTの同時成立率は不明）。
- 工程ごとの判断に必要な情報を一画面で記録し、JSONバックアップ（プランに内包）・判断レポートで保存可能。
- v1.2からの所持馬、名牝登録、研究案・仮馬、P1〜R2、9工程連結結果はそのまま維持します。

限界
- 至高の配合成立確定／奇跡の配合判定・兄弟クロスの完全判定は未実装。ゲーム内表示を確認して登録してください。
- 子系統のSP/ST効果、ニトロの確定加算値、最終産駒の能力の数値予測はできません。ゲノム値はユーザーが入力したゲーム内解析値のみです。
- 研究案の並び替え指数は実際のSP/ST期待値や公式BCの勝率ではありません。
