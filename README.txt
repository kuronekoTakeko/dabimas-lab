ダビマス配合研究所 v2.5｜1因子・年号付きの至高候補照合修正
確認日：2026-11-06

【目的】
ユーザーが実際に取得している「キングカメハメハ2012」（底1因子）を、
「キングカメハメハ-翔瑚-」（走・長・短）
「キングカメハメハ-覇禊-」（堅・速）
と同じキングカメハメハの至高一次候補として抽出できるようにする。

【修正内容】
1. CSVの「キングカメハメハ2012」など4桁年号が末尾にある登録馬は、
   検索上の基礎名「キングカメハメハ」と登録バリエーション「2012」に分けて評価。
   原ID「キングカメハメハ2012」は一切書き換えない。
2. v2.4以前にIndexedDBへ保存した公開CSVマスターを再読込した場合も、
   検索用の基礎名・バリエーションだけメモリ上で再構成する。
3. 至高候補は3因子馬だけでなく1因子・2因子・3因子を対象にし、
   同一名の異なる登録ID3頭で6種類以上になる場合は研究上の一次候補として表示。
   1因子馬を追加独立クロス探索の全工程に適用する一般化は未実装。
4. 今回の所有者による「キングカメハメハ2012を実際に取得した」という申告を反映。
   キーが保存データに存在しない場合だけ「owned:true, rights:0, verified:user_report_2026-11-06」
   を一度追加。あとからチェックを外した場合、次回起動時に勝手に戻さない。
   権利数0は未所持ではなく未入力を意味し、探索の除外条件にしない。
5. 至高候補一覧と自動設計の説明を「1～3因子・年号付き」に対応させる。
6. PWAのバージョン表記、JSクエリ番号とサービスワーカーのキャッシュ名をv2.5へ更新。
