ダビマス配合研究所 v1.0（配合候補の研究用比較）

更新機能
- 9工程を保存前に仮想的に一括計算し、公開繁殖牝馬P1/P2/Q1/Q2/R1/R2と所持補助種牡馬Xの候補を探索。
- 5代血統31枠の祖先・因子を再計算し、短・速・走と長・中の因子位置数、4〜5代のSP/ST研究対象子系統位置数、追加クロスを比較。
- 目的（スピード／スタミナ／バランス）で並び替えの重みを変更。全探索ではなく最大36牝馬と最大28頭Xによる複数初期解の局所探索。
- 比較上位3案を一覧表示し、選択した研究案だけ別プランへ保存。元の9工程と既存自家製馬記録は変更しない。
- 新プランには候補牝馬・Xを9工程に入力済み、登録済み仮馬へのリンクは白紙にして血統の再連結が可能。
- v0.2以来のlocalStorage保存キー、CSV取り込み形式、既存プラン、所持チェック、JSONバックアップ形式との互換を保持。

ご注意
- 順位は任意の研究指標に基づく暫定比較で、馬の実際のSP/STやニトロ計算、公式BC勝率、至高成立の証明ではありません。
- 牝馬は公開マスターから選んでおり、ユーザーの所持／市場入手可否を確認していません。
- SP/STの最低ラインと予想値は根拠が不足するため自動設定していません。ゲーム内のゲノム解析・生産実測で確認してください。
- 血統情報が欠ける場合は候補を無理に生成しません。
- 一括探索は全組み合わせの総当たりではありません。重複クロスや全兄弟姉妹阻害条件の自動判定は未完成です。

更新の手順
1. v0.9でデータ管理→JSON書き出し。
2. ZIP内の6ファイルをGitHubリポジトリ直下に上書きアップロード。
3. 強制再読み込み（Windows: Ctrl+Shift+R）。
4. 保存済み9工程プランを開き、v1.0欄で比較を実行。
5. 任意の研究案を別プランに保存し、原案が残っていることを確認。
