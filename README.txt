ダビマス配合研究所 v2.0｜親5代血統とゲーム風血統表

【v1.9からの更新内容】
・最終種牡馬、最終肌馬、最終産駒の血統をそれぞれ5代相当の種牡馬祖先31枠で可視化。各世代を横並びにしたゲーム風の研究用UI。
・産駒5代内で検出した独立クロス候補は赤字。至高3×4×5指定位置は金色枠。親の5代に見えるものの産駒5代外にある候補は橙点線で区別。
・新しく作る自家製馬は最大31枠（5代）の祖先名・因子を次工程のために記録。従来の15枠保存から拡張。
・旧バックアップの15枠自家製馬は父母IDが有効なら表示時に31枠を再構成。元の保存データは自動上書きしない。
・公開馬マスターが4代までしか提供しない系譜は、祖先馬自身が公開マスターにある場合、確かな一致がとれる位置だけ親側5代へ補完。未収録は空欄。
・CSVに「祖先位置_因子3」という列が存在する場合だけ3番目の因子も読み込む。元CSVに列がない場合は追加データを捏造しない。
・v1.9の所持馬からの自動配置（13工程）、有効クロス因子、名牝研究案、JSONバックアップは継続。

【重要な区別】
①産駒5代内の独立クロス候補：v1.6の既知因名集計対象。ゲーム内の正式成立ではない。
②親馬それぞれの5代のうち産駒5代外にある祖先：参考表示のみ。ゲーム内で有効なクロスとして数えたとは主張しない。
③ニトロ・SP/ST・子系統ボーナス：実ゲームの確定値を計算したものではない。
④現行公開CSVが祖先3因子列を欠く場合、その情報を自動取得できない。因名未確認は未確認のまま。
⑤血統表は種牡馬祖先位置を示す研究用UIであり、全牝馬を含むゲーム本体画面の完全な複製ではない。

【使い方】
1. GitHub更新前に「データ管理」でJSONバックアップを書き出す。
2. ZIPの6ファイルをリポジトリ直下に上書き、Commit changes。
3. 「保存プラン」から13工程案や9工程案を開く。
4. 13工程を試算した後、または最終9工程を仮連結した後、v2.0の血統表を開く。
5. 産駒・最終種牡馬・最終肌馬の順に切り替えて、赤字クロスと金枠の至高位置を確認する。
6. 古い端末の公開CSVから新しい祖先3因子情報を取り直したい場合は「データ管理」でCSVを再取込（配信元に列がある場合のみ）。

【保存互換性】
localStorage保存キー dabimas_lab_v02_state は維持。バックアップのバージョンはv13形式のまま（アプリのv2.0と別）。
