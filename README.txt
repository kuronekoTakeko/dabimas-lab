ダビマス配合研究所 v0.5（2026年11月）

【新機能】
保存プラン上で3×4×5の仮配置をもとに、CSVに存在する祖先を5代の範囲で追跡します。
・因子6種類の一次条件、祖先位置、登録済みの祖先名・因子・子系統を表示
・同じ祖先の追加出現を注意として表示（特殊配合の不成立と同義ではありません）
・同じ因名3頭の祖先配置6通りを比較し、選択欄へ反映
・子系統の研究分類に基づき、所持種牡馬／全マスターから補助素材候補を提示
・工程のSP/ST最低基準の未記入数を表示
・所持チェック、保存プラン、メモ、ゲノム解析入力をv0.4から継続

【注意】
・これはCSVからわかる「部分的な5代血統」であり、繁殖牝馬P1などの未指定親馬を含めた血統全体は確定しません。
・至高や奇跡の成立確定、ニトロ総数、子系統の実数値補正、SP/ST予想能力、各工程の最低能力の自動計算はまだ未実装です。
・3因子の種類数だけで実戦の強さが決まるわけではありません。
・同名の祖先が複数登場しても必ず成立阻害となるわけではありません。
・補助候補は実際の配合可能性を保証するものではありません。
・公開CSVは同梱しません。公開元から各自で読み込む方式です。配布物に第三者のCSVを複製していません。
・更新前にv0.4で「データ管理 → JSON書き出し」を推奨します。同じURLで上書きすると現行の所持・保存プランを保持する設計です。
