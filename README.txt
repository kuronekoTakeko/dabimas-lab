ダビマス配合研究所 v0.6（2026-11-04）

新機能：
・5代血統の種牡馬位置31枠に対する「確認できた祖先位置」を表示
・補助種牡馬X（最終産駒のDDS＝母母父）の検索
・所持馬／全マスターから、Xを入れた場合の祖先・因子・研究上の子系統を暫定比較
・プレビューのみ／保存して工程7に反映、を分ける
・選択したXの血統スナップショットを配合プランとJSONバックアップに保存
・6通りの配置比較へ選択中のXを反映
・所持馬チェック、保存済みプラン、ゲノム記録は従来どおり引き継ぎ

【重要】
・同じ種牡馬名の異なる因名を3×4×5に配置した一次候補の検討用です。至高の成立は保証しません。
・X検索順位は登録血統の確認範囲と研究対象系統に基づく「調査の便宜上の順位」であり、ゲーム内SP/ST能力値・勝率の予測ではありません。
・繁殖牝馬P1 P2 Q1 Q2 R1 R2は未指定のままで、補助Xを選んでも完全な血統・ニトロ・子系統補正は計算できません。
・母系の全兄弟姉妹と特殊条件は未検証です。ゲームで成立を確認してください。
・工程の最低許容SP/STは未設定のままです。根拠のない数値を表示しません。
・第三者が公開しているCSVはZIPに同梱しません。参照元のライセンスにご注意ください。
