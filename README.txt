【v2.4の主な改修】
1. 「本気型」の追加クロス探索で、3因子＋3因子だけでなく3＋2因子、2＋2因子の同名異因名ペアも評価。
   旧v1.7・v2.2の保存プランや3因子限定UIは変更せず、最新の自動設計にのみ適用。
2. 取得済み種牡馬は権利数0でも含める。未取得種牡馬を自動仕込みに採用しない。
3. 同名・異因名ペアの重い試算は多様な馬名と因子数の組合せを優先した上位24組に制限。
   2因子馬を含む単独仕込み候補も追加。
4. 固定の補助X（完成産駒のDDS位置）に、自家製牡馬を最大2世代仕込む枝を追加。
   最終産駒の5代血統内に有効な種牡馬祖先が残り、研究スコアが改善する場合のみ採用。
   すべての仮馬の父・母・必要な性別・生産順・未生産状態を保存。
5. 本気型の理論上の探索枠は従来の基本9工程＋母系仕込み9工程＋補助X仕込み2工程＝最大20工程。
   構造上の上限であり、毎回20工程を生成する保証・推奨ではありません。
6. 名牝6頭・補助Xの初期選択は上位3基礎案を比較（従来上位2案）。5代の31種牡馬枠を再計算。
7. 本気型の保存プランに新規仕込み工程の完了状態・最低SP/ST・結果・メモを編集できる欄を継承。
8. ホーム画面の旧「13～15工程」という説明とPWAのキャッシュ識別子を更新。
