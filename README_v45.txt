ダビマス配合研究所 v4.5｜自動中心馬選択（開発版）
更新日：2026-11-07

【今回の実装】
・自動設計で「所持種牡馬から自動選択」を初期選択に追加。
・最大120組の至高一次候補から研究指数上位最大6組を抽出し、各候補について名牝6頭＋補助種牡馬Xの探索を行って血統品質・研究根拠・既存の候補順位を照合。
・採用した中心馬と比較件数をプランの autoDesign21.autoAnchor45 に記録。
・手動指定の従来フローも残す。
・旧プランのデータ構造と保存キー、所持馬315頭JSONの形式は変更しない。
・ZIPには初期化用315頭JSONを含めない。

【重要：現時点の制限】
・全315頭×全名牝の組み合わせの厳密な大域最適解ではありません。自動比較は上位6中心馬候補の部分探索です。
・検索にはユーザーの公開マスターCSV、名牝の収録・区分が必要です。ZIPだけで全名牝の完全血統を利用可能にはなりません。
・マイルドは9工程固定であり、自動短縮は未完成です。
・本気型は旧実装の9～20工程の上限付き探索です。
・全兄弟姉妹阻害、ゲーム内至高成立、最新の全公式血統の照合、ブラウザ実操作、ゲーム実機は未検証です。
・今回追加の自動選択はコード・静的統合テストまで。実データによる大規模探索の動作時間・順位は未測定です。

【今後の仮完成条件】
1. 公式ダビマス全書を優先参照して各祖先のID・因子・子系統の検証済みマスターを整備（利用条件を確認し無断一括複製しない）。
2. ダビふぁく・dbms-pd-makerとの許可された範囲での独立照合と不成立パターンの自動テスト。
3. 中心馬＋名牝＋工程の広域探索、改善度に応じた工程短縮、親子リンクの完全検証。
4. 実ブラウザの生成・保存・復元・オフラインテスト。仮完成後の実機生産は最優先1プランに絞る。

【更新手順】
旧PWAで現在の保存データをJSONバックアップしてから、展開ファイルをGitHub Pagesのリポジトリに上書きしてください。
ブラウザや端末ごとにlocalStorageは分離しています。初期JSONを復元すると現在データが上書きされる可能性があるため、初期化用JSONは使わないでください。
