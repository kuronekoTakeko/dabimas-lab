ダビマス配合研究所 v4.7
========================
更新日: 2026-11-09
基盤: v4.6 ZIP

変更内容
- 本気型の候補比較を「先に選んだ1組の中心異因名セット内のみ」から、複数の成立一次候補セットをまたぐ比較に改善。
- 確認済みの血統構造・根拠を優先して上位3基礎候補を選び、可能なら異なる中心3頭セットを1つずつ含める。
- 各候補で既存の可変仕込み探索を実行し、血統品質・研究評価・工程効率で最終採用を比較。
- 採用した中心馬3頭IDと深掘り比較件数をプランのautoDesign21に記録。
- マイルド型の9工程ロジックは変更なし。
- 既存の所持315頭・保存プラン・ゲノム・自家製馬のストレージ形式は変更なし。
- 新モジュール research-global-shortlist.js をSWキャッシュへ登録。

重要な制限
- 3案の深掘りという探索上限があります。数学的な大域最適解は保証しません。
- 全兄弟姉妹の阻害条件、ゲーム内至高成立、SP/ST予想能力は検証していません。
- 外部有志ツールとの数値照合・公開マスターとの網羅的突合は今回未実施。
- 実際の最終血統・産駒を使ったゲーム内検証は未実施。
- 実ブラウザを使った手動の自動設計クリック・保存フローの総合操作試験は未実施。
- 公開マスターCSVが別途必要。ZIPに第三者のCSVや独自の所持JSONを同梱していません。

テスト
- node tests/v*.test.js <所有データJSONパス> により 122件合格
- うち v4.7追加8件。旧テストはバージョン47のscript/cache参照に追随。
- JS構文チェック合格。
- ZIP形式のCRCチェック合格。
- 画面表示だけのブラウザ起動チェックは環境により未実施の可能性があります。

データの安全
- 公開ZIPには初期化用315頭のJSONを含めていません。
- 更新前にはPWAの「データ管理」からJSONバックアップを保存してください。
- 各PCのlocalStorageは自動同期しません。
